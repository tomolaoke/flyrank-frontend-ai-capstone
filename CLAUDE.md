# AI Assistant Rules (Claude/Cursor)

## Stack
- Node.js (LTS)
- Git for version control
- Cursor IDE (AI-assisted development)

## Conventions
- Use Conventional Commits format:
  - `feat:` for new features
  - `fix:` for bug fixes
  - `docs:` for documentation
  - `chore:` for setup/maintenance
- Branch naming: `feature/<name>` or `fix/<name>`
- All code reviewed with AI assistant before commit

## AI Usage
- AI assistant will critique documentation and suggest improvements.
- AI assistant may generate starter code, but all outputs are reviewed manually.
